# Slice specs

- One file per slice: `slice-N.md` (e.g. `slice-5.md`).
- Sections are numbered, and every spec ends with the line `<!-- END OF SPEC -->` so truncation is obvious.
- Don't backfill specs for finished slices. Exception: `slice-1.md` to `slice-4.md` are documentation of work shipped before this folder existed, written on 2026-10-11 from the commit history and the code. They are not build instructions; "run slice N" on them means the slice is already implemented.
